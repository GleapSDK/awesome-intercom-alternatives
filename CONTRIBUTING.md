# Contributing

Pull requests welcome. Keep it factual and keep it short.

- **One product per row**, alphabetical inside its table. A product may appear in more than one table if it fits both.
- **Link a public vendor page** (pricing, docs or feature page) in the PR description for every cell you add or change.
- **Boolean columns follow the legend in the README.** Trials are not free plans. WebView embeds are not mobile SDKs. Chatbot builders are not AI agents.
- **Pricing model** is a short phrase describing how the vendor charges, not a price. Prices change too often for a table.
- **Not sure?** Use ➖ and say why in the PR.
- No marketing copy, superlatives or "best for" claims in any cell.
